# Contributing to WiFi QR Reader

Obrigado por se interessar em contribuir!

## Como Contribuir

1. **Fork** o projeto
2. Crie uma branch para sua feature (`git checkout -b feature/MinhaFeature`)
3. Commit suas mudanças (`git commit -m 'Adiciona nova feature'`)
4. Push para a branch (`git push origin feature/MinhaFeature`)
5. Abra um **Pull Request**

## Relatórios de Bugs

Use o [GitHub Issues](https://github.com/MarbleCeo/wifi-qr-reader/issues) para relatar bugs.

Inclua:
- Descrição detalhada do problema
- Passos para reproduzir
- Versão do app
- Distribuição Linux

## Sugestões

Sugestões de features são bem-vindas! Abra uma issue com a tag `enhancement`.

## Código de Conduta

Seja respeitoso e construtivo com todos os contribuidores.
